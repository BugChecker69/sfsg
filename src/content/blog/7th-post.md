新世紀エヴァンゲリオンに登場するスーパーコンピュータ「MAGI（マギ）」といえば、人類の存亡をかけた重大な意思決定を3つの人格（科学者・母・現実主義）による合議制で下す未来のシステムです。昨今の生成AIやマルチエージェント技術の目覚ましい発展により、ついにあの合議プロセスを現代のPC上でリアルに再現できるようになりました。

今回は、3つの独立した最新フロンティアLLM（OpenAI、Anthropic、Google Gemini）をそれぞれ異なる思考人格として並列稼働させ、ユーザーの提示した議題に対して「可決」「否決」「保留」の多数決合議を行う「MAGI SYSTEM」を実際に作ってみたので、その仕様と使い方をご紹介します。

## 1. システム概要

本システムは、エヴァンゲリオンの「MAGI」の合議決定プロセスを模したマルチエージェント意思決定エンジンです。
3つの異なるAIモデルを並列稼働させ、多角的な視点から議論・判定を行います。

![MAGI SYSTEM システム利用画面](/sfsg/public/MAGI%20SYSTEM.webp)

## 2. システム構成・技術仕様

### 2.1 アーキテクチャ構成
* **フロントエンド / UI**: Streamlit（Pythonベースの軽量WebUI）
* **オーケストレーション**: Python `concurrent.futures.ThreadPoolExecutor` による3基並列非同期実行
* **タイムアウト制御**: スレッド側およびAPIクライアント側で厳格な制限（最大8〜10秒）を設け、レスポンスの無限ハングを排除
* **エラー検知機能**: 廃止・非推奨モデル（404 / deprecated等）の自動検知アラートをUI最上部に表示

### 2.2 審議ユニット（エージェント）定義

| ユニット名 | ペルソナ（判断基準） | 採用モデル | APIプロバイダ |
| :--- | :--- | :--- | :--- |
| **MELCHIOR-1** | 科学者（論理・客観データ・技術的合理性） | `gpt-4o-mini` | OpenAI |
| **BALTHASAR-2** | 母・人道主義（倫理・調和・長期的安全） | `claude-haiku-5-5` | Anthropic |
| **CASPER-3** | 現実主義（実効性・生存戦略・リソース効率） | `gemini-3.5-flash-lite` | Google GenAI |

### 2.3 総合判定ロジック
* **【可決】満場一致**: 3基すべてが「可決」
* **【可決】多数決**: 2基が「可決」
* **【否決】満場一致**: 3基すべてが「否決」
* **【否決】多数決**: 2基が「否決」
* **【保留】**: 意見が分かれた場合、または1基以上が「保留」を出した場合

## 4. 日常の使用方法

### 4.1 起動手順（現在設定済みの端末）
* **方法A（ショートカット）**: デスクトップの `MAGI_SYSTEM.bat` をダブルクリック
* **方法B（PowerShellから手動起動）**:
  ```powershell
  cd C:\Users\user\magi-system
  .\venv\Scripts\Activate.ps1
  streamlit run app.py
  ```

### 4.2 審査の実行
1. ブラウザが自動的に開き、MAGI SYSTEM画面（黒基調UI）が表示されます。
2. 「審査議題を入力してください」のテキストボックスに審査したい命題を入力します。
3. **[審議開始 (DELIBERATE)]** ボタンをクリックします。
4. 数秒（約2〜5秒）で合議結果が判定され、総合判定および各ユニットの判定・理由が表示されます。

### 4.3 適切な議題の入力形式
* **推奨（Yes/No形式・政策的命題）**:
  * 「〜すべきか？」
  * 「〜は〜であると認定すべきか？」
  * 「科学技術により、今世紀中に人間の平均寿命を120歳まで延伸することは可能か？」
* **非推奨（オープンエンド・数値のみを問う形式）**:
  * 「人間の寿命は何歳まで伸びるか？」等の問いは、合議の性質上「保留」になりやすくなります。
