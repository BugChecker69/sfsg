I-BO（アイボー）です。

朝起きたとき、「今日の天気」「傘がいるかどうか」「今日入っている予定」を別々のアプリやサイトで確認するのが手間に感じていました。

そこで、Googleの無料プログラム実行環境（Google Apps Script / GAS）を使い、毎朝決まった時間に「今日の天気予報」「当日のGoogleカレンダーの予定」「LINE通知の残り枠」をひとまとめにしてLINEへ自動送信する仕組みを作りました。

サーバー代などの維持費は一切かからず、完全無料で安定して動いています。

## 1. 毎朝届く通知のイメージ

実際に毎朝届いているLINE通知画面です。

```text
【本日の定期通知】
・日中最高気温: 21℃
・明日朝の最低気温: 16℃
・降水確率: 70%

※雨具の携帯を推奨します。

──────────────
【本日の予定】
・19:30 - 20:00 氏家歯科

──────────────
【LINE無料枠残数】
今月使用: 14 / 200通
当月残り: 186通
```

朝起きてLINEの通知を一度開くだけで、その日一日の行動に必要な情報がひと目で把握できます。

---

## 2. 実現している機能と仕組み

このシステムでは、主に3つの情報を1つのメッセージに組み立てて送信しています。

### ① 当日の天気予報と傘のアドバイス
気象庁が一般公開しているオープンデータ（JSON形式）から、当日の「日中の最高気温」「明日朝の最低気温」「降水確率」を自動で取得しています。
* 降水確率が 40% 以上の場合：`※雨具の携帯を推奨します。`
* 降水確率が 30% 以下の場合：`※傘の心配は少なそうです。`
上記のように、状況に応じたアドバイス文言も自動で判定・付与されます。

### ② 当日のGoogleカレンダーの予定
普段使っているGoogleカレンダーから、その日（0:00〜23:59）に入っている予定を自動で抜き出してリスト化します。
「19:30 - 20:00 氏家歯科」のように開始・終了時刻付きで表示されるため、当日のスケジュール確認漏れを防げます。なお、予定が何もない日は「本日の予定はありません」と表示されます。

### ③ LINE無料枠の残数カウント
個人開発者向けのLINE公式アカウント（フリープラン）は、プログラムから送信できるメッセージが「月200通まで」という上限があります。
うっかり上限に達して通知が止まってしまわないよう、LINE Messaging APIの統計情報エンドポイントへ自動で問い合わせを行い、今月何通使ってあと何通残っているかをメッセージの末尾に自動追記しています。

## 3. 開発における工夫とポイント

### 無料枠を使い切らないための「1通集約」
「天気予報で1通」「予定の通知で1通」と分けて送信すると、あっという間に月の無料上限（200通）を消費してしまいます。
天気・予定・残数の3つの情報をプログラム内部で1つのテキストに合体させて送信することで、1日の消費通数を確実に「1通（月約30通）」に抑え、余裕を持って無料運用を続けられるように設計しています。

### 安定稼働のためのデータソース選定
一般的な外部のお天気Webサービスの中には、アクセスの回数制限が厳しかったり、無料枠が急に終了したりするものがあります。
そこで、アクセスの制限や仕様変更のリスクが極めて低い気象庁の公式データを直接参照する仕組みを採用し、毎朝エラーなく確実に届く安定性を確保しました。

## 4. サンプルコード（Google Apps Script）

実際にGAS上で動かしている処理のイメージ（骨組み）は以下の通りです。

```javascript
function sendDailyNotification() {
  // 1. 天気情報の取得 (気象庁APIなど)
  const weatherText = "【本日の定期通知】\n・日中最高気温: 21℃\n・明日朝の最低気温: 16℃\n・降水確率: 70%\n\n※雨具の携帯を推奨します。";

  // 2. カレンダー予定の取得
  const calendarText = "【本日の予定】\n・19:30 - 20:00 氏家歯科";

  // 3. LINE残数の取得
  const lineQuotaText = "【LINE無料枠残数】\n今月使用: 14 / 200通\n当月残り: 186通";

  // メッセージを1通に統合
  const message = `${weatherText}\n\n──────────────\n${calendarText}\n\n──────────────\n${lineQuotaText}`;

  // LINEへ送信
  sendToLine(message);
}

function sendToLine(message) {
  const token = "YOUR_LINE_ACCESS_TOKEN";
  const url = "https://api.line.me/v2/bot/message/broadcast";
  
  const payload = {
    messages: [{ type: "text", text: message }]
  };

  const options = {
    method: "post",
    headers: {
      "Content-Type": "application/json",
      "Authorization": "Bearer " + token
    },
    payload: JSON.stringify(payload)
  };

  UrlFetchApp.fetch(url, options);
}
```

## 5. まとめ

スマートフォンを開いて複数のアプリを巡回するのではなく、「必要な情報が毎朝1通にまとまって届く」状態を作るだけで、朝の準備のわずらわしさが大幅に解消されます。

GoogleのアカウントとLINE公式アカウントさえあれば誰でも追加コスト0円で構築できるため、日々の小さな手間を減らす自動化の第一歩として非常に実用的です。
